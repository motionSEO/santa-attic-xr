# 컨베이어 테이블 버전 (복제본)

https://motionseo.github.io/santa-attic-xr/conveyor/

원본(저장소 루트, https://motionseo.github.io/santa-attic-xr/)을 복제해서, 작업 테이블이 컨베이어 벨트처럼 오른쪽 벽 → 정면 → 왼쪽 벽으로 한 단계씩 넘어가는 버전이에요 (`modules/conveyor.js`).
1. 배쓰밤 제작 테이블: 재료·도구 전부 (허브 화분, 병 선반, 서랍장, 바구니, 절구, LUSH 레시피북)
2. 포장 테이블: 책장에 있던 포장지 롤 → 포장 → 손편지 → 니콜라스에게 선물과 편지 전달 → 니콜라스가 뒷주머니에서 다른 산타의 선물을 꺼내 줌
3. 수반 테이블: 받은 선물을 수반에 놓으면 포장이 찢어지고 배쓰밤이 거품을 내며 녹음 → 엔딩 카드 → 25초 뒤 니콜라스 작별 인사 후 문으로 퇴장 → 페이드아웃

용량을 아끼려고 바뀌지 않은 큰 파일(`room.glb.js`, `trees.glb.js`, `room.glb`, `Sound/BGM`)은 상위 폴더의 것을 그대로 씁니다. 개발 원본은 `claude/project-thread-txxicw` 브랜치예요.
