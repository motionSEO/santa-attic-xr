# Santa Attic · 1인칭

크리스마스 산타 배쓰밤 XR 게임의 다락방 공간을 1인칭으로 걸어다닐 수 있게 만든 버전이에요.
기존 프로토타입(`Dear-Stranger-from-Santa`)은 그대로 두고 따로 복제해서 작업해요.

## 체험 흐름 (원본 프로토타입과 같은 순서, 지금은 임시 그래픽)
시작 → 벽난로에 불이 붙고 산타의 편지가 날아옴 → 01 레시피북에서 마음 고르기 → 02 레시피 확인 → 03 공통 베이스(선반의 병 쏟기) →
03~04 자연재료(화분, 과일 바구니, 서랍, 선반) 손질해서 절구에 넣기 → 05 빻기 5번 → 06 틀에 붓기, 누르기, 열기 → 07 장식 →
08 포장 → 09 그림 편지 → 마법 수반에 넣어 보내기 → 다른 산타의 선물 받기. 화면 위 안내(VR은 떠 있는 말풍선)가 다음 할 일을 알려줘요.
- PC: 클릭한 채 = 집기, Space = 손 동작(자르기, 짜기, 부러뜨리기, 빻기, 누르기), R 키를 누른 채 = 기울이기(쏟기, 붓기, 뿌리기), 휠 = 거리
- 퀘스트3 손: 집기/주먹으로 잡기, 손가락 끝으로 책·버튼·서랍 누르기, 반대 손으로 잡아 부러뜨리기, 절굿공이를 내리쳐 빻기, 손바닥으로 뚜껑 누르기
- 진짜 에셋으로 바꾸는 방법은 `ASSETS.md`

## 조작
플레이어는 작업대 앞 한 자리에 서 있고 움직이지 않아요(걷기, 순간이동 없음). 시점만 돌릴 수 있어요.
도구와 재료는 그 자리에서 손이 닿게 배치했어요. 책장 서랍, 벽난로처럼 먼 것은 가리켜서 다뤄요.
- 데스크톱: 오른쪽 버튼을 누른 채 끌기 = 시점 돌리기, 왼쪽 클릭 = 커서 위치의 물건과 상호작용(누른 채 끌면 들고 옮기기)
- 모바일: 화면 드래그 = 둘러보기
- 퀘스트3 핸드트래킹: 엄지+검지 집기 = 작은 것 집기/허브 따기, 주먹 = 병·절구·머그 잡기, 손 펴기 = 놓기,
  손가락 끝 = 책·버튼·잉크병 누르기. 멀리 있는 것은 손으로 가리키면 빛줄기가 닿고, 그 상태에서 집으면 손으로 날아오거나(물건) 열려요(서랍)
- 퀘스트3 컨트롤러: 트리거 = 집기(멀리 가리키기 포함), 그립 = 주먹, 오른쪽 스틱 = 30° 회전

## 파일
- `index.html` 메인 페이지 (three.js 0.169 + WebXR, 충돌은 three-mesh-bvh)
- `room.glb` 다락방 모델 (Blender에서 내보낸 원본, 20MB)
- `modules/herbs.js` 허브 채취 + 손/컨트롤러/마우스 입력
- `modules/mug.js` 코코아 머그 (김, 마시기, 다시 채우기)
- `modules/flow.js` 체험 흐름 전체 (단계, 임시 오브젝트, 책/편지 UI, 에셋 교체)
- `ASSETS.md`, `assets/*.example.json` 에셋 전달 형식과 교체 설정 예시
- `herb-test.html`, `mug-test.html` 모듈 단독 테스트 페이지
- `lighting.json`, `area_lights.json` Blender 조명 값 (참고용), `run.bat` 윈도우 로컬 실행

## 실행
- PC: GitHub Pages 주소를 크롬/엣지로 열기, 또는 `run.bat` 더블클릭
- 퀘스트3: 헤드셋 브라우저에서 GitHub Pages 주소(HTTPS) 열기 → `ENTER VR`. 손 추적은 퀘스트 설정 > 움직임 추적 > 손 추적이 켜져 있어야 해요
